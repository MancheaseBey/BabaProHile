# BabaProHile → Mobil Hedefleme Laboratuvarı

Depodaki önceki HTML/Android arayüz denemesi korunmuştur. Yeni bağımsız Unity 3D eğitim projesi `UnityProject/` altındadır.

**Güvenlik kapsamı:** Bu uygulama yalnızca kendi sahnesindeki kuklalar üzerinde 3D hedefleme, görüş açısı ve ekran etiketi mantığını öğretir. Harici oyunlara bağlanma, oyun belleği okuma, enjeksiyon veya çevrimiçi oyunlarda avantaj sağlayan entegrasyon içermez.
